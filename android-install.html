Android 위젯 설치

휴대폰 카메라로 QR코드를 스캔하거나, 휴대폰에서 아래 버튼을 누르세요.

My Calendar 위젯 다운로드

다운로드한 다음 이렇게 하세요

  1. 다운로드 완료 알림을 누르세요.알림이 사라졌다면 ‘내 파일 → 다운로드 → MyCalendar-Android-Widget-debug.apk’를 누르세요.
  2. 설치 차단 안내가 나오면 ‘설정’을 누르세요.현재 브라우저의 ‘이 출처 허용’ 또는 ‘알 수 없는 앱 설치 허용’을 켠 뒤 뒤로 이동합니다.
  3. ‘설치’를 누르세요.기존 앱이 있다면 ‘업데이트’를 선택하세요. 설치가 끝나면 ‘열기’를 누릅니다.
  4. My Calendar에서 캘린더 권한을 허용하세요.‘캘린더 권한 허용’ 버튼을 누르고 Android 권한 창에서 허용합니다. 완료된 버튼은 자동으로 비활성화됩니다.
  5. 홈 화면을 길게 누르고 ‘위젯’을 여세요.My Calendar에서 오늘 일정 2×1, 주간 4×2, 월간 4×3, 일정 목록 4×2, 월간＋일정 4×5의 실제 미리보기를 보고 원하는 위젯을 선택할 수 있습니다.
  6. 위젯을 길게 눌러 ‘설정’을 여세요.일정 표시 방식, 배경 투명도, 글씨 크기를 바꾸면 홈 화면 위젯에 바로 반영됩니다. 위젯의 톱니바퀴에서도 같은 설정을 열 수 있습니다.
  7. 위젯 본문을 누르면 My Calendar가 열립니다.앱의 ‘위젯 설정’과 ‘My Calendar 열기’ 버튼으로도 각각 설정 화면과 실제 캘린더를 열 수 있습니다.

Android 전용 시험 설치본입니다. QR코드는 다운로드 페이지를 여는 용도이며 Android의 설치 보안 확인을 우회하지 않습니다.
