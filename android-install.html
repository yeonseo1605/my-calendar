Android 위젯 설치

휴대폰 카메라로 QR코드를 스캔하거나, 휴대폰에서 아래 버튼을 누르세요.

My Calendar 위젯 다운로드

다운로드한 다음 이렇게 하세요

  1. 다운로드 완료 알림을 누르세요.알림이 사라졌다면 ‘내 파일 → 다운로드 → MyCalendar-Android-Widget-debug.apk’를 누르세요.
  2. 설치 차단 안내가 나오면 ‘설정’을 누르세요.현재 브라우저의 ‘이 출처 허용’ 또는 ‘알 수 없는 앱 설치 허용’을 켠 뒤 뒤로 이동합니다.
  3. ‘설치’를 누르세요.기존 앱이 있다면 ‘업데이트’를 선택하세요. 설치가 끝나면 ‘열기’를 누릅니다.
  4. My Calendar에서 캘린더 권한을 허용하세요.‘캘린더 권한 허용’ 버튼을 한 번 누르고 Android 권한 창에서 허용합니다.
  5. 웹 설정을 가져오세요.앱의 ‘웹 설정 가져오기’ → 표시 방식 선택 → ‘설정 적용 및 위젯 추가’를 누릅니다.
  6. Android의 위젯 추가 창에서 ‘추가’를 누르세요.추가 창이 나오지 않으면 홈 화면을 길게 누른 뒤 ‘위젯 → My Calendar’를 선택하세요.

Android 전용 시험 설치본입니다. QR코드는 다운로드 페이지를 여는 용도이며 Android의 설치 보안 확인을 우회하지 않습니다.
