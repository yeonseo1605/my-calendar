Android 위젯 설치

휴대폰 카메라로 QR코드를 스캔하거나, 휴대폰에서 아래 버튼을 누르세요.

My Calendar 위젯 다운로드
  1. APK를 다운로드하고 설치합니다.
  2. 처음 설치할 때 표시되면 브라우저의 ‘알 수 없는 앱 설치’를 허용합니다.
  3. 앱을 열어 캘린더 접근 권한을 허용합니다.
  4. 홈 화면을 길게 누른 뒤 ‘위젯 → My Calendar’를 선택합니다.

Android 전용 시험 설치본입니다. QR코드는 다운로드 페이지를 여는 용도이며 Android의 설치 보안 확인을 우회하지 않습니다.
